Google Maps API key

This page uses Google Maps itself (with Satellite and Street View), so it needs your Maps JavaScript API key. The key is stored only in this browser.

How to get a key
  1. Open Google Cloud's Maps Platform and create a project (it asks for billing, but personal use stays inside the free monthly allowance).
  2. Enable the Maps JavaScript API. Also enable the Elevation API if you want profiles for GPX files that have no elevation data in them.
  3. Under Keys & Credentials, create an API key and limit it to those APIs.
